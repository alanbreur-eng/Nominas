Reglas de cancelación

El bono comienza a partir de la 4ª venta y se paga al 100% una vez que se generen ventas de manera constante cada semana.

El bono queda condicionado: si una venta se cancela, la próxima semana se le descontará el bono al agente de ventas por la razón que ya se le pagó por esa venta.

El gerente de cobranza dará seguimiento a las canceladas. En caso de tener canceladas consecutivas se revisará y se podrá retener el bono.

Ejemplo: 1 venta cancelada → vender 5 paquetes para recuperar el bono completo; 2 canceladas → vender 6 paquetes; 3 canceladas → vender 7 paquetes; así sucesivamente.
